# Mio CLI 国际化

Mio 的轻量 i18n 层使用静态消息表，支持 `zh-CN`、`ja-JP` 和 `en-US`。语言属于单次 CLI 调用上下文，不使用进程级可变语言状态。

语言选择顺序如下：

1. CLI `--lang`
2. `MIO_LANG`
3. `LC_ALL`、`LC_MESSAGES`、`LANG`
4. `en-US`

`zh_CN.UTF-8`、`ja_JP.UTF-8`、`en_US.UTF-8` 等常见 Locale 会自动归一化。未知语言回退到 `en-US`。

本地化只影响面向人的标签与汇总。源码字符串、测试名、路径和用户断言消息保持原文。JSON 字段名、状态值与错误代码不翻译，因此同一 CI 解析逻辑不受本地 Locale 影响。
