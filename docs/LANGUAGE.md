# Mio v0.1 语言说明

本文记录 `v0.1.0-alpha.1` 已实现的源码语法与静态类型规则。未在本文列出的语法不能视为可用功能。

## 源文件与词法规则

Mio 源文件使用 UTF-8。标识符由 ASCII 字母或下划线开头，后续可包含 ASCII 字母、数字和下划线。整数字面量使用十进制；除 `0` 外不能带前导零。

字符串使用双引号，支持 `\n`、`\r`、`\t`、`\"` 和 `\\` 转义。字符串不能直接跨行。

```mio
// 单行注释
/* 多行注释 */
chant("Mio\n");
```

语句以分号结束。函数声明和代码块本身不加分号。

## 关键字

| 关键字 | 含义 |
| --- | --- |
| `kaku` | 声明变量 |
| `waza` | 声明函数 |
| `moshi` | 条件分支 |
| `sore` | 否则分支 |
| `kaesu` | 从函数返回 |
| `hai` | 布尔真 |
| `iie` | 布尔假 |
| `mu` | 空值 |

关键字采用日语罗马音拼写，区分大小写。

## 类型

### `int64`

`int64` 是有符号 64 位整数。支持 `+`、`-`、`*`、`/` 和一元负号。除法向零截断，除零产生运行时错误。

整数运算沿用 v0.1 的二进制补码回绕语义。加、减、乘或取负超出 `int64` 范围时保留低 64 位；`MinInt64 / -1` 的结果仍为 `MinInt64`。

### `bool`

布尔值写作 `hai` 和 `iie`。`!` 执行逻辑非，`&&` 和 `||` 执行短路求值。`moshi` 条件必须是 `bool`。

### `string`

`string` 保存 UTF-8 文本。v0.1 支持字符串的 `==` 和 `!=`，不支持拼接或大小比较。

### `nil`

`mu` 是空值字面量，运行时显示为 `mu`。v0.1 不能从 `mu` 推断变量类型，也没有可用于变量或参数标注的 `nil` 类型名。`mu` 不支持相等比较。

### `unit`

`unit` 表示函数没有返回值。它只用于函数返回类型，不会进入运行时 Value Stack，也不能保存到变量或传给 `chant`。

## 变量与作用域

`kaku` 从初始化表达式推断变量类型。后续赋值必须保持相同类型。

```mio
kaku count = 1;
count = count + 1;
chant(count);
```

每个 `{}` 代码块创建词法作用域。内层声明可以遮蔽外层变量，赋值会修改名称解析到的既有变量。

```mio
kaku value = 10;
moshi (hai) {
    kaku value = 20;
    chant(value);
}
chant(value);
```

变量必须先声明再使用。同一作用域不能重复声明同名符号。

## 条件分支

```mio
moshi (score >= 60) {
    chant("passed");
} sore {
    chant("failed");
}
```

`sore` 可以省略。v0.1 没有循环语句。

## 函数

函数只能在文件顶层声明。每个参数必须带类型，函数必须声明返回类型。

```mio
waza add(a: int64, b: int64) -> int64 {
    kaesu a + b;
}

waza show(value: int64) -> unit {
    chant(value);
    kaesu;
}
```

支持在声明前调用、递归和相互递归。非 `unit` 函数必须在所有静态可见路径上返回正确类型；`unit` 函数可使用 `kaesu;`，函数末尾也会隐式返回。

函数可以读取和修改可见的全局变量。v0.1 不支持嵌套函数、函数值或闭包。

## 内置函数

`chant(value)` 输出一个值并追加换行。参数可以是 `int64`、`bool`、`string` 或 `nil`，返回类型是 `unit`。

```mio
chant(42);
chant(hai);
chant("hello");
chant(mu);
```

## 运算符

从高到低的优先级为：

1. 函数调用 `()`
2. 一元 `-`、`!`
3. `*`、`/`
4. `+`、`-`
5. `<`、`<=`、`>`、`>=`
6. `==`、`!=`
7. `&&`
8. `||`

二元运算符左结合。算术和大小比较只接受 `int64`；相等比较要求两侧类型一致，并仅支持 `int64`、`bool` 和 `string`。

## 资源限制

VM 的 Value Stack 最多保存 65,536 个值，同时存在的用户函数调用最多 1,024 层。每次执行默认最多运行 10,000,000 条指令，并可通过 Go API 的 `context` 提前取消。超过限制会产生运行时错误。

## 后续版本范围

循环、集合、用户定义类型、模块和导入尚未实现。源码中出现这些语法会被当前前端拒绝。
